# Sahara verification map

Start from a fresh page at the exact deployment URL or the isolated local server launched by `npm run verify`. Sound begins off. The default mode moves creatures, wind and sand unless the browser requests reduced motion. No stored user state exists.

- [Look around](look-around.md): pointer and keyboard 360-degree exploration in every scene.
- [Travel](travel.md): chapter buttons, scoped navigation swipes and keyboard navigation.
- [Encounters](encounters.md): caravan, wind, sandfish and fennec invitations, scene picking and return.
- [Motion and sound](motion-sound.md): pause, reduced-motion mode, opt-in wind audio.
- [Desert notes](notes.md): dialog, escape, sources and narrow screens.

Capture real actions and observable end states. UI assertions alone do not prove visual quality. Each scene needs phone and laptop pixels and all four quadrants. A skipped input path stays unverified even when another route works.
